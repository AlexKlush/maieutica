# Майевтика

Сократический тьютор: после короткого текста (сейчас — про OKR) ведёт структурированный диалог, где ученик рассуждает сам.
Конвейер: диагностика реплики → модель ученика (BKT) → педагогическая политика → генерация → проверка. LLM — GigaChat.
Подробности — в [PRODUCT.md](PRODUCT.md) и [research/REPORT.md](research/REPORT.md).

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Без ключа приложение тоже запускается — в **автономном режиме** (см. ниже). Проверка, что всё живо: `http://localhost:8501/_stcore/health` отвечает `ok`.

## Подключение GigaChat

Ключ (Authorization key из личного кабинета GigaChat API) берётся из первого найденного источника:

| Источник | Как задать |
|---|---|
| переменная окружения | `GIGACHAT_CREDENTIALS=...` (и при необходимости `GIGACHAT_SCOPE`, по умолчанию `GIGACHAT_API_PERS`) |
| Streamlit Secrets | `GIGACHAT_CREDENTIALS = "..."` в `.streamlit/secrets.toml` или в Settings → Secrets |
| файл `.env` | строка `GIGACHAT_CREDENTIALS=...` (в `.gitignore`) |

Модели по ролям (диагностика / генерация / проверка) — `GigaChat-2-Max`. Все три роли можно заменить одной переменной, например `GIGACHAT_MODEL=GigaChat-2`, а по отдельности — секцией `[models]` в Secrets.

Приложению нужен исходящий доступ к `ngw.devices.sberbank.ru:9443` (OAuth) и `gigachat.devices.sberbank.ru:443` (API). Сертификаты Минцифры лежат в `certs/`. Адреса можно переопределить (`GIGACHAT_AUTH_URL`, `GIGACHAT_API_URL`).

## Автономный режим

Если ключа нет, сеть закрыта или GigaChat не отвечает, тьютор не падает, а отвечает **по правилам, без нейросети**: реплику ученика разбирают ключевые слова и карта знаний урока, ответ собирается из банка вопросов, подсказок и контрпримеров урока. Политика, модель ученика и проверка по правилам работают как обычно, но реплики проще и однообразнее.

- В интерфейсе это видно: красный блок «Автономный режим» с причиной в боковой панели и пометка «автономно» у каждого такого хода.
- После сбоя соединения GigaChat помечается недоступным на 45 с (при повторных сбоях — дольше, до 10 минут), чтобы приложение не ждало таймаутов. Кнопка «Проверить подключение» возвращает GigaChat в работу.
- Оценка качества (`eval/`) автономный режим **не использует**: любой сбой LLM там виден, а не подменяется правилами.

## Диагностика

```bash
python -m maieutica.doctor            # ключ, сеть, OAuth, запрос по каждой роли, автономный режим
python -m maieutica.doctor --json     # то же машиночитаемо
```

Код возврата: `0` — GigaChat отвечает, `2` — работает только автономный режим, `1` — что-то сломано.

Тесты (`pytest`) идут без сети. Весь путь запросов можно прогнать и без настоящего ключа — на заглушке API:

```bash
python -m tests.fake_gigachat 8765 &
GIGACHAT_CREDENTIALS=fake GIGACHAT_AUTH_URL=http://127.0.0.1:8765/api/v2/oauth \
GIGACHAT_API_URL=http://127.0.0.1:8765/api/v1 streamlit run app.py
```

## Структура

`app.py`, `app.css` — интерфейс · `maieutica/` — конвейер (`analyzer`, `policy`, `learner`, `generator`, `verifier`, `engine`, `offline`, `llm`, `doctor`) · `lessons/` — уроки как данные · `eval/` — оценка на симулированных учениках · `research/` — обзор литературы · `tests/`.
